petra-catalogs API¶

Public package¶

petra: from the LISA global fit to catalogs of single sources.

The public entry points are the two make_catalog_* relabelers, load_samples() and PosteriorChain. import petra is cheap: the entry points are resolved on first access (PEP 562), so jax is not imported until a flow method is used. The package is typed (py.typed), and the lazy names are also imported under TYPE_CHECKING so a type checker sees their real signatures. A chain is (n_samples, n_sources, n_params_per_source) and an all-NaN source row means the source is absent. Nothing prints: diagnostics go to the petra logger, and progress=False silences every progress bar.

Catalog entry points¶

The multivariate-normal catalog method: relabel_mv_normal and the entry point make_catalog_mv_normal.

Every make_catalog_* entry point takes (posterior_chain, max_num_sources, *, ...) with the shared keywords num_iterations, initialization_param_index, shuffle_seed, rng_seed, checkpoint_dir, resume_from, progress and eps, checks its arguments before any work, never modifies its input and returns a new chain.

Build a catalog: widen, shuffle, warm-start with a univariate pass, then relabel with multivariate normals.

Parameters:

  • posterior_chain (PosteriorChain) – chain to catalog, holding at least one sample; never modified.

  • max_num_sources (int) – number of labels in the catalog, at least the chain’s num_sources.

  • num_iterations (int) – ceiling on the multivariate iterations, counting split-move evaluations and resumed ones.

  • init_num_iterations (int) – ceiling on the univariate warm start’s iterations; checked even when it is skipped.

  • initialization_param_index (int | None) – parameter of the univariate warm start, or None to skip it.

  • shuffle_seed (int | None) – None for no shuffle, else a non-negative integer; the chain is widened before it is shuffled.

  • rng_seed (int) – accepted for symmetry with the other entry points and unused.

  • checkpoint_dir (str | PathLike[str] | None) – directory to save the best labeling to each time it improves; created and checked first.

  • resume_from (str | PathLike[str] | None) – checkpoint file or directory to resume from, without shuffling, widening or initializing again.

  • progress (bool) – show a progress bar over the samples of each iteration.

  • eps (float) – clip bound on prob_in_model inside the cost matrix; costs under different values are not comparable.

  • keep_checkpoints (int | None) – keep only this many of the newest checkpoints; None keeps them all.

  • split_moves (bool) – where the search would stop, try splitting a label that holds two clusters of rows.

  • split_exclusive (bool) – with split_moves, also split a label whose two clusters rarely appear in the same sample.

  • num_starts (int) – independent starts, start k shuffled with shuffle_seed + k (or k, start 0 unshuffled).

Returns:

The strictly cheapest start’s catalog of max_num_sources labels, with unclipped prob_in_model; cost_dict[max_num_sources] is its labeling’s cost under the fit before it.

Raises:

  • TypeError – posterior_chain is not a PosteriorChain, or shuffle_seed is not None or an integer.

  • ValueError – a count, eps, max_num_sources, shuffle_seed, initialization_param_index or the checkpoint is invalid, or num_starts > 1 is combined with checkpoint_dir or resume_from.

  • OSError – checkpoint_dir cannot be created or written to.

Warns:

UserWarning – a label that widening added ends empty; with split_moves, the budget ran out before the search stopped; a resume has nothing left to run.

Return type:

Chains and sample loading¶

The PosteriorChain container and its Feather file format.

A chain is stored as native float64 (n_samples, num_sources, num_params_per_source); an all-NaN row is an absent source. Metadata is strict JSON under FEATHER_METADATA_KEY; legacy padded-column files still read.
